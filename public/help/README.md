## Знайдіть відповідь

Використовуйте пошук у змісті ліворуч. На телефоні відкрийте його кнопкою меню. Підрозділи поточної сторінки додаються до змісту автоматично.

[Усунення проблем](guide/troubleshooting.md) · [Часті запитання](guide/faq.md)

> Попередній огляд плану та AI-пропозиція ще не означають збереження змін. Перевіряйте результат явного підтвердження. За невизначеної відповіді спочатку перевіряйте актуальні записи.

Знімки показують справжній поточний інтерфейс із вигаданими демонстраційними даними браузерних перевірок. Це ілюстрації користування, а не свідчення доступності зовнішнього AI чи доставки нагадувань на вашому сервері.

Посібник відкритий для всіх і не читає особисті навчальні дані. Для повернення скористайтеся посиланням «До Student AI Planner» угорі. Документація та її пошук не потребують Laravel або сторонніх CDN; потрібні JavaScript і доступ до статичних файлів сайту.
