# Інвентар маршрутів і перевірки

Джерело: `src/router/index.ts`, HEAD `7150d8ff1fc6a3463c2ac50148734ea4908c7792`. 56 записів роутера; вкладених `children` немає, вкладені URL наведено окремо. Інвентар не означає повне приймання всіх станів. У таблиці скорочено регулярні обмеження: `:id`/`:rule` — числа, weekday — 1–5, section — institutions, periods, subjects або teachers.

До змін відкрито основні сторінки на 320 CSS px. «404» нижче означає перевірений стан помилки й **неперевірений наповнений екран**: відповідного запису немає у поточного локального демонстраційного користувача. Справжні записи не створювались.

## Меню та поповери

- `AppNavigation`: desktop links, mobile links, `<details>` «Більше», зовнішня допомога; `useNavigationDisclosure` лишає Escape, клік поза меню й закриття після зміни маршруту.
- `PlanningNav`: `<details>` «Час і налаштування».
- `TaskSubtasks` / `TaskEditorView`: додаткові дії підзавдань, нативний popover і контекстні меню.
- `AiView`: розгортання історії та списку дій; `AiActionReview`: окремі згоди.
- `<details>` доказів, джерел Excel, графіків і додаткових причин лишені доступними; дії не приховувались CSS.
