# Завершення роботи поруч із дією

Модальний `WorkCompletionDialog.vue` замінено на `WorkCompletionPrompt.vue`. Блок відображається в картці відповідного завдання або в рядку підзавдання, без затемнення та блокування фокуса в діалозі.

Перший клік відкриває огляд; запис виконується тільки після «Підтвердити завершення». «Назад» закриває блок без запису. Для підзавдання збережено чинний запуск через позначку виконання: до підтвердження вона залишається незаповненою.

Коли `future_sessions_count > 0`, показано одне повідомлення: «Майбутні заплановані сесії буде скасовано, а час у плані звільниться.» та серверний лічильник. За нульового лічильника тексту про скасування немає, залишаються кнопки підтвердження й повернення. Список сесій, дати, пошук, вибір сесії та фактичні хвилини прибрано з цього сценарію разом із відповідними запитами.

## Серверний контракт

Перед змінами прочитано `AGENTS.md`, перевірено чисте робоче дерево та гілку `main`. Контракт звірено з локальним `../student-planner-backend`, корінь підтверджено через `git rev-parse --show-toplevel`. Backend не редагувався.

Збережено `GET .../completion-review` і один `POST .../complete` з `completion_token`. Підтвердження у вбудованому блоці замінює повторне браузерне вікно згоди. Backend перевіряє токен для точного набору майбутніх сесій і виконує скасування. Минулі сесії не позначаються завершеними. Статуси у Vue не встановлюються оптимістично.

Збережено перевірки актуальності завдання/підзавдання перед записом. Помилки показуються в цьому ж блоці. Застарілий або невизначений результат потребує нового огляду; автоматичного повтору запису немає. Успіх показується лише за підтвердженим статусом `completed`.

Підтвердження видалення та сценарій спільного завершення зі сторінки навчальної сесії не змінено.
