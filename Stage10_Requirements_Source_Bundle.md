> Це консолідована **дослівна текстова копія** завантажених користувачем джерел. Орфографія та формулювання вихідних абзаців не виправлялися. Заголовки між файлами додано лише для розмежування джерел. Фактичну пріоритетність вимог необхідно погодити з користувачем.


## 1. Тема та постановка задачі (джерело: Тема-та-постановка-задачі-проєкту.txt)


Розробка AI-агента для сервісу персонального планування навчальної діяльності студента.

Розробити AI-агента для сервісу персонального планування навчальної діяльності студента. Сервіс має забезпечувати зберігання, перегляд та редагування розкладу занять, а також керування навчальними завданнями: створення, редагування, встановлення дедлайнів, пріоритетів і статусів виконання. Необхідно реалізувати імпорт розкладу занять із файлів Excel, визначення вільних часових проміжків між заняттями та відображення актуальної інформації про заплановані справи й навчальне навантаження студента.

AI-агент повинен підтримувати взаємодію з користувачем природною мовою та самостійно визначати послідовність необхідних дій для виконання запиту. Агент має забезпечувати отримання інформації про розклад і завдання, створення та редагування завдань, пошук вільного часу, автоматичне формування персонального плану навчання з урахуванням дедлайнів, пріоритетів, тривалості завдань і часових обмежень користувача. Також необхідно передбачити механізми перенесення невиконаних завдань, створення нагадувань, статистичного аналізу виконання навчальних завдань і формування звітів про прогрес студента.

Як працюватиме агент
Користувач:
До понеділка потрібно виконати курсову з КПЗ.
Знайди для неї час, але не плануй роботу після 20:00.
AI-агент:
1. Викликає get_schedule.
2. Викликає get_assignments.
3. Викликає find_free_slots.
4. Розподіляє роботу на декілька етапів.
5. Викликає create_study_plan.
6. Пропонує створити нагадування.
7. Після підтвердження викликає create_reminder.
Агент не просто дає текстову рекомендацію, а змінює реальні дані системи: створює завдання, будує розклад, додає нагадування та переносить незавершені справи.
Основні функції системи
* перегляд розкладу;
* ведення завдань і дедлайнів;
* персональне планування навчання;
* визначення пріоритетів;
* автоматичне перенесення незавершених завдань;
* нагадування;
* статистика виконання;
* командне планування;
* чат з AI-агентом.

Тестування
| Вид тестування | Приклад                                                             |
| -------------- | ------------------------------------------------------------------- |
| Unit           | Розрахунок вільного часу, пріоритетів і тривалості навчальних сесій |
| Integration    | Взаємодія агента, бази даних, розкладу та календаря                 |
| E2E            | Створення плану від текстового запиту до появи подій у календарі    |
| AI-тести       | Перевірка правильності вибору tools і їхніх параметрів              |
| Smoke          | Вхід, перегляд розкладу, створення завдання, запит до агента        |
| Regression     | Перевірка системи після зміни алгоритму планування                  |
| Security       | Контроль доступу до розкладів і завдань інших користувачів          |
| Performance    | Робота системи з великою кількістю занять і завдань                 |
| System         | Перевірка повної системи в тестовому середовищі                     |
Приклади AI-тестів

| ------------------------------------- | -------------------------------------------------------- |

| «Не плануй нічого після 20:00»        | Дотримання користувацького обмеження                     |
CI/CD та розгортання
Проєкт передбачатиме:
1. Зберігання коду в GitHub.
2. Автоматичне складання після кожного Pull Request.
3. Запуск Unit та Integration тестів.
4. Запуск E2E-тестів у Playwright.
5. Запуск набору AI-тестів.
6. Перевірку якості коду.
7. Створення Docker-образу.
8. Автоматичний deployment у staging.
9. Виконання smoke-тестів після розгортання.
10. Ручне підтвердження production deployment.
11. Відкат версії у випадку невдалих smoke-тестів.
